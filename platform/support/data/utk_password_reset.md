# UT Knoxville password reset

Institution: University of Tennessee, Knoxville
Source: https://utk.teamdynamix.com/TDClient/2277/OIT-Portal/KB/PrintArticle?ID=113585
Reviewed: 2026-10-22
Tags: utk, university-helpdesk, password-reset

Use the NetID Online Password Reset tool if you forgot your password. Online reset requires prior setup of the reset option and the verification requested by the university. Initial Password Setup is for accounts that have never had a password. Allow up to 15 minutes for the new password to reach Microsoft 365 and Google. If reset options fail, contact OIT; in-person assistance is available at the OIT Service Center in Hodges Library. Enter identity-verification details only in the official university process, never in this chatbot.

This is a concise project-authored summary of public guidance. Consult the official source for current procedures. This prototype is not an official UT service.

OIT software availability depends on affiliation, device ownership, and license conditions. Use the OIT Software Distribution site linked from the official software page. Apps@UT runs applications remotely and is available to active UTK faculty, staff, and students. Cloud applications may be provided through vendor websites. Check each product's current eligibility and terms rather than assuming all software is free or licensed for personal devices.

This is a concise project-authored summary of public guidance. Consult the official source for current procedures. This prototype is not an official UT service.

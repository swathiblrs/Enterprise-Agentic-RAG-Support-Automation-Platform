# UT Knoxville Microsoft 365

Institution: University of Tennessee, Knoxville
Source: https://oit.utk.edu/microsoft365/
Reviewed: 2026-10-22
Tags: utk, university-helpdesk, microsoft365

Microsoft 365 for Education offers eligible UT faculty, staff, and students email, Office web applications, and document storage. Teams supports conversations, meetings, and file collaboration. OneDrive provides file storage and sharing; quotas depend on affiliation. Active eligible users can install Office desktop applications without an additional charge, but the subscription ends after leaving the university. Verify current eligibility through OIT before promising a particular license or storage quota.

This is a concise project-authored summary of public guidance. Consult the official source for current procedures. This prototype is not an official UT service.
